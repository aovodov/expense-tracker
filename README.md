# Учёт расходов

Небольшое приложение на Python для учёта расходов в командной строке и его автотесты.
Проект показывает, как запустить автотесты на своём компьютере и загрузить результаты
в Allure TestOps.

## Что понадобится

- **Python 3.10 или новее.** Скачать: <https://www.python.org/downloads/>.
  На Windows при установке отметьте «Add python.exe to PATH».
- **Аккаунт в Allure TestOps** с правом загружать результаты в проект.
- **Доступ в интернет.** Скрипты скачивают зависимости с PyPI и утилиту allurectl с GitHub.

Для прохождения практикума понадобится Git. Для загрузки в свой проект можно скачать архив.

## Практикум в локальном TestOps

Создайте проект «Практикум: учёт расходов» в TestOps и выполните команды в терминале:

```sh
git clone https://github.com/aovodov/expense-tracker.git
cd expense-tracker
python3 run.py
python3 upload.py --practice
```

В Windows используйте `py` вместо `python3`. На ветке `main` ожидаются 27 успешных тестов
и 3 падения. После прогона выполните команду загрузки и войдите с логином и паролем от TestOps.
По умолчанию скрипт подключается к `http://localhost:8080`. Если доступно несколько практикумов,
введите ID своего проекта. Он указан в адресе страницы после `/project/`.

Откройте ссылку `Report link`, чтобы посмотреть результаты. Затем переключитесь на `fixed`
и повторите прогон и загрузку в тот же проект:

```sh
git switch fixed
python3 run.py
python3 upload.py --practice
```

Во втором запуске должны пройти все 30 тестов.

## Загрузка в свой проект по API-токену

Скачайте проект: на странице репозитория нажмите **Code** и выберите **Download ZIP**,
затем распакуйте архив. Либо выполните `git clone https://github.com/aovodov/expense-tracker.git`.

Откройте терминал в папке проекта и запустите два скрипта.

На Windows:

```
py run.py
py upload.py
```

На macOS и Linux:

```
python3 run.py
python3 upload.py
```

| Скрипт | Что делает |
|---|---|
| `run.py` | Создаёт виртуальное окружение, устанавливает зависимости и запускает автотесты. Результаты сохраняются в папку `allure-results`. |
| `upload.py` | Скачивает утилиту allurectl и загружает папку `allure-results` в ваш Allure TestOps. |

При первом запуске `upload.py` спросит три параметра:

- **Адрес Allure TestOps** — например, `https://testops.example.com`.
- **API-токен** — создайте его в TestOps: нажмите на аватар, выберите **API-токены**,
  нажмите **+ Токен**, введите название и нажмите **Создать**.
- **ID проекта** — число в адресе страницы проекта, после `/project/`.
  Например, в адресе `https://testops.example.com/project/124/launches` это `124`.

Адрес и ID проекта скрипт запоминает, поэтому при втором запуске спросит только токен.
Токен скрипт не сохраняет.

Параметры можно задать и заранее, тогда вопросов не будет:

```
python upload.py --endpoint https://testops.example.com --project-id 124
```

Токен в командной строке лучше не писать. Задайте его переменной окружения `ALLURE_TOKEN`.

## Что умеет приложение

| Команда | Что делает |
|---|---|
| `python -m expense_tracker add 2026-11-24 еда 350,50 "Обед"` | Добавляет расход. Вместо даты можно написать `today`. |
| `python -m expense_tracker list --month 2026-11 --category еда` | Показывает расходы, можно отфильтровать по месяцу и категории. |
| `python -m expense_tracker report --month 2026-11 --budget 30000` | Отчёт за месяц и остаток бюджета. |
| `python -m expense_tracker export expenses.csv` | Сохраняет расходы в файл CSV. |
| `python -m expense_tracker import expenses.csv` | Добавляет расходы из файла CSV. |

Расходы хранятся в файле `expenses.json` рядом с проектом.

## Правила работы приложения

Автотесты проверяют эти правила:

1. Сумма расхода должна быть больше нуля.
2. Сумма принимается и с точкой, и с запятой: `350.50` и `350,50` — одно и то же.
3. Дата указывается в формате `ГГГГ-ММ-ДД`.
4. Категория не зависит от регистра: «Еда» и «еда» — одна категория.
5. Суммы выводятся с двумя знаками после запятой: `12.50 руб.`
6. Бюджет превышен только тогда, когда расходы строго больше бюджета.
   Расходы, равные бюджету, — не превышение.
7. Импорт из CSV загружает все строки файла, включая последнюю.

## Ветки

- **`main`** — в коде есть три дефекта. Их находят три автотеста, поэтому из 30 тестов
  проходят 27:

  | Упавший тест | Что не работает |
  |---|---|
  | Сумма выводится ровно с двумя знаками после запятой | Сумма печатается как `12.5 руб.` вместо `12.50 руб.` (нарушено правило 5) |
  | Расходы равны бюджету — бюджет не превышен | При расходах, равных бюджету, приложение сообщает о превышении (нарушено правило 6) |
  | Импортируются все строки файла, включая последнюю | При импорте из CSV теряется последняя строка файла (нарушено правило 7) |

- **`fixed`** — те же три дефекта исправлены. Проходят все 30 тестов.

Чтобы получить зелёный запуск, переключитесь на ветку `fixed` и повторите оба скрипта:

```
git switch fixed
python run.py
python upload.py
```

Если проект скачан архивом, скачайте архив ветки `fixed`: на странице репозитория выберите
ветку `fixed`, нажмите **Code** и **Download ZIP**.

## Как всё устроено без скриптов

Оба скрипта заменяют несколько обычных команд. Вот они целиком:

```
python -m venv .venv
.venv/bin/pip install -r requirements.txt      # Windows: .venv\Scripts\pip install -r requirements.txt
.venv/bin/python -m pytest                     # Windows: .venv\Scripts\python -m pytest

curl -L -o allurectl https://github.com/allure-framework/allurectl/releases/latest/download/allurectl_darwin_arm64
chmod +x allurectl
ALLURE_TOKEN=<API-токен> ./allurectl upload --endpoint https://testops.example.com --project-id 124 allure-results
```

Имя файла allurectl зависит от системы и процессора, полный список — на странице
[релизов allurectl](https://github.com/allure-framework/allurectl/releases).
Папка с результатами называется `allure-results`. Перед каждым запуском pytest очищает её,
чтобы в следующую загрузку не попали результаты прошлой.

## Структура проекта

```
expense_tracker/          приложение
  money.py                суммы: разбор строки и вывод
  ledger.py               реестр расходов: добавление, отбор, суммы
  budget.py               месячный бюджет
  storage.py              файлы JSON и CSV
  cli.py                  команды
tests/                    автотесты pytest
run.py                    запускает автотесты
upload.py                 загружает результаты в Allure TestOps
pytest.ini                настройки pytest: папка для результатов Allure
requirements.txt          зависимости
```
